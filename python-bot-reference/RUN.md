# Голосовой трекер — Telegram-бот (этап 1)

## Запуск за 5 минут

```bash
pip install -r requirements.txt
cp .env.example .env      # вписать BOT_TOKEN и LLM_API_KEY
python main.py
```

## .env

| Переменная | Что это |
|---|---|
| BOT_TOKEN | токен от @BotFather |
| LLM_BASE_URL | https://api.proxyapi.ru/openai/v1 (РФ) или https://api.openai.com/v1 |
| LLM_API_KEY | ключ провайдера |
| LLM_MODEL | gpt-4o-mini (дёшево и хватает) |
| STT_MODEL | whisper-1 |
| ALLOWED_IDS | твой Telegram ID (узнать у @userinfobot). Пусто = бот открыт всем |
| RATE_PER_MIN / RATE_PER_DAY | лимит обращений к ИИ, по умолчанию 10 и 150 |
| MAX_VOICE_SEC | максимальная длина голосового, по умолчанию 300 сек |
| DADATA_TOKEN | опционально, для DaData. Без него работает ГИР БО ФНС - бесплатно |
| API_PORT | порт HTTP API, по умолчанию 8080 |
| DEV_USER_ID | только для локальной отладки без Telegram; на проде оставить пустым |

## Безопасность

Обязательно заполни `ALLOWED_IDS` до того, как дашь ссылку на бота кому-либо. Телеграм-боты находятся поиском по имени: без белого списка любой посторонний сможет слать голосовые и тратить твой платный API. Файл `.env` в `.gitignore` — не выкладывай его в репозиторий, утёкший `BOT_TOKEN` означает полный контроль над ботом.

STT_BASE_URL и STT_API_KEY можно не задавать — берутся из LLM_*.

## Как пользоваться

- `/start` — короткий опрос, настраивает вкладки под сферу
- голосовое сообщение — основной сценарий: наговорил, бот разобрал на карточки, задачи и события
- текстовое сообщение — то же самое, но текстом
- `/tasks` — открытые задачи с номерами
- `/done 12` — закрыть задачу №12
- `/clients` — все карточки с потенциалом и числом задач
- `/inn 7712345678` — тянет из ФНС название, регион, ОКВЭД и выручку, сразу заводит карточку
- `/report` — отчёт за 7/14/30 дней, текстом или файлом

## Что внутри

| Файл | Назначение |
|---|---|
| main.py | хендлеры, онбординг, рендер ответов |
| ai.py | расшифровка речи, разбор в JSON, генерация отчёта |
| db.py | SQLite: users, entities, tasks, events, raw_logs |
| config.py | все ключи и провайдеры в одном месте |
| company.py | поиск по ИНН: ГИР БО ФНС, при наличии токена - DaData |
| api.py | HTTP API для приложения поверх той же базы |
| GLOSSARY.md | терминология Элкома для LLM-разбора: дивизионы, типы клиентов, города, деньги, формула продаж |
| formula.py | оценка сделки по формуле РП+ФВ+ЛПР+ОБО+СМЗ+СНО+КП, копится по клиенту со временем |

`raw_logs` хранит исходную расшифровку и JSON разбора — на них потом дорабатывается промпт, ничего не теряется.

## Деплой на VPS

```bash
sudo apt install python3-venv -y
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
# systemd-юнит, чтобы бот жил после закрытия консоли:
sudo tee /etc/systemd/system/tracker.service >/dev/null <<'UNIT'
[Unit]
Description=Voice tracker bot
[Service]
WorkingDirectory=/root/bot
ExecStart=/root/bot/venv/bin/python main.py
Restart=always
[Install]
WantedBy=multi-user.target
UNIT
sudo systemctl enable --now tracker
```

## Доработка разбора

Терминология для разбора речи - в `GLOSSARY.md`, отдельно от кода: правишь список городов или добавляешь сленговое название дивизиона там, не трогая `ai.py`. Промпт разбора - `EXTRACT_SYSTEM` в `ai.py`, сам GLOSSARY.md подставляется в него автоматически. Именно он решает, что бот вытащит из речи. Стиль отчёта — `REPORT_SYSTEM` там же.


## Связка с приложением

Бот и приложение работают с одной базой. Голосовое, разобранное ботом,
сразу видно в приложении; карточка, заведённая в приложении, видна боту.

API поднимается тем же процессом, что и бот - отдельно запускать не нужно.

| Метод | Путь | Назначение |
|---|---|---|
| GET | /api/state | всё состояние: клиенты, проекты, задачи, файлы |
| POST | /api/clients | создать или обновить карточку клиента |
| POST | /api/projects | создать или обновить проект |
| POST | /api/tasks | добавить задачу или переключить статус |
| GET | /api/company?inn= | данные по ИНН из ФНС |

Авторизация - по `initData` Telegram Mini App, подпись проверяется на сервере
ключом бота. Без корректной подписи API отвечает 401, подставить чужой
user_id и прочитать чужую базу нельзя.

Фронтенду нужно указать адрес API до загрузки приложения:

```html
<script>window.TRACKER_API = "https://ваш-домен";</script>
```

Без этой строки приложение работает автономно на локальном состоянии
и показывает в шапке метку «локально».


## Формула продаж

Внутренняя методика Элкома: РП + ФВ + (ЛПР+ОБО) + СМЗ + СНО + КП = 6 баллов =
100% сделка. Каждый элемент - конкретный факт, а не общие слова. После
каждого голосового бот пересчитывает балл по клиенту и, если до 6 не хватает,
прямо в ответе пишет, каких элементов не хватает - это подсказка, что
спросить на следующей встрече, а не наказание.

Балл копится: то, что узнали месяц назад, не стирается новым голосовым, где
об этом просто не упомянули. Перезаписывается только если по тому же
элементу пришла новая, более свежая конкретика.

Подробное описание каждого элемента с примерами «конкретно / расплывчато» -
в `GLOSSARY.md`, раздел «Формула продаж».
