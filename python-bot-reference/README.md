# Python-прототип (справочный, не основной стек проекта)

Основной бэкенд проекта - `src/server/*` (NestJS/Express + PostgreSQL),
именно он собирается и деплоится (см. корневой README и `docs/ARCHITECTURE.md`).

Эта папка - параллельный прототип на Python/aiogram/SQLite, из которого
стоит забрать логику при портировании на основной стек:

- `formula.py` - оценка сделки по формуле РП+ФВ+ЛПР+ОБО+СМЗ+СНО+КП,
  накопительный подсчёт по клиенту
- `GLOSSARY.md` - терминология Элкома для промпта LLM: дивизионы, типы
  клиентов, города, формула продаж с примерами "конкретно/расплывчато"
- `company.py` - поиск компании по ИНН через ГИР БО ФНС (бесплатно, без ключа)
- `db.py` / `api.py` - схема данных и HTTP-эндпоинты, для сверки с моделью
  в `src/server/services/crm.ts`

Дальше см. README.md в этой же папке - инструкция по запуску прототипа
отдельно, если нужно свериться в работе вживую.
