# Импорт компаний в Pico

Отправьте боту файл XLSX, CSV или TXT. Для XLSX используйте один лист без формул, макросов, внешних ссылок и объединённых ячеек. Лимиты: файл до 2 МБ, до 100 компаний и 30 колонок; значения до 1000 символов. CSV/TXT — UTF-8. Для старого Excel `.xls` сохраните копию в `.xlsx`.

Первая строка таблицы — заголовки. Обязательна только колонка «Название компании» (также допустимы «Название», «Компания», `name`, `company`). Дополнительные поля: ИНН, город, тип клиента, отрасль, стадия, выручка, потенциал, заметки и потенциал по направлениям. Категории и стадии должны совпадать со значениями CRM; русские подписи поддерживаются. Суммы — в рублях; заголовок «Потенциал млн руб» явно задаёт миллионы. Общий потенциал не вычисляется из направлений и не выдумывается при отсутствии.

Pico показывает предпросмотр, источник строки и отсутствующие поля. До нажатия «Подтвердить импорт» компании не создаются. Дубли по названию/ИНН пропускаются, существующие записи не обновляются и их ответственные не меняются. Новый клиент принадлежит фактическому вошедшему сотруднику. Повторное подтверждение не создаёт компании второй раз. Предпросмотр действует 30 минут; после истечения отправьте файл снова.

Если тип клиента в источнике не указан, новая запись сохраняется с категорией «Тип не указан». Это не означает «Заказчик». Техническая стадия новой записи CRM — «Новый», если стадия не задана в файле; это явно сообщается в предпросмотре. Изменение типа при ручном редактировании — отдельное решение пользователя. Существующие ручные настройки и компании не переписываются.

Для Google Docs отправьте обычную публичную ссылку `https://docs.google.com/document/d/ID/edit` или экспорт документа в TXT/CSV. Приватные документы требуют экспорта самим владельцем: Pico не запрашивает доступ к вашему Google-аккаунту. В TXT можно перечислить по одному названию компании на строку либо использовать блоки:

```text
Название: Энергопроект
Город: Санкт-Петербург
Тип: Проектный институт

Название: Промышленный заказчик
Потенциал: 4500000
```

Внешние запросы ограничены Google Docs с проверкой HTTPS, публичного IP, сроков ожидания и размера; переходы на другие адреса не выполняются. Если публичный документ не удаётся экспортировать, отправьте файл. Google Sheets можно экспортировать в XLSX/CSV; прямое подключение приватных Docs/Sheets не добавлено.

Не включайте личные контакты, пароли и секреты. Импорт принимает поля компаний, а не произвольные персональные данные; запрещённые колонки и распознанные контактные/секретные значения отклоняются до сохранения. Это не заменяет отдельную системную задачу предварительной фильтрации всех каналов ввода. Распознавание голоса не изменено по решению пользователя.

Протокол импорта локальный и не отправляет содержимое файла в AI. Неизвестные колонки явно пропускаются; отсутствующие сведения не ищутся в интернете и не заполняются предположениями.
