# Информационные письма ESQ

В карточке компании нажмите «Создать письмо». Без контактов под кнопкой появляется ошибка. Один контакт выбран автоматически; при нескольких нужно выбрать адресата. Должность контактного лица должна быть заполнена в CRM. Данные CRM автоматически не изменяются.

В разделе «Мой профиль» → «Подписи для писем» можно создать до трёх личных подписей, редактировать их и удалять с подтверждением. В форме создания загрузите визитку JPEG/PNG до 10 МБ либо заполните поля вручную. Проверьте распознанные данные и нажмите «Сохранить изменения». Распознавание само по себе ничего не сохраняет. Изображение обрабатывает OpenAI, исходное фото не сохраняется на диске приложения.

В форме письма нажмите «Моя подпись» и выберите сохранённую подпись. Если подпись одна, она выбрана автоматически. Пункт «+ Добавить подпись» открывает форму создания; после сохранения новая подпись выбирается для текущего письма. При трёх подписях добавление недоступно. Если подписей нет, список содержит только «+ Добавить подпись». Удаление подписи не меняет готовые PDF. Сайт добавляется только в PDF и не отображается в приложении.

«Сформировать PDF и сохранить» создаёт письмо в разделе «Файлы». Получатель берётся из выбранного контакта. Интернет-поиск проверяет компанию и определяет отрасль; референсы берутся из `assets/esq/REFERENCES_ESQ.md`. Оформление основано на предоставленном архиве. В шапке номер и дата занимают левую колонку, адресат — правую, с промежутком между ними. Длинные строки автоматически переносятся по фактической ширине шрифта, без уменьшения размера текста. Заголовок и основное содержимое располагаются ниже более высокой колонки. При переполнении страницы абзац референсов сокращается, число попыток ограничено; непомещающееся письмо не сохраняется как готовое. Уже сохранённые PDF не изменяются: исправленная вёрстка применяется при новой генерации. Исходящие номера 1000–9999 не повторяются для сотрудника; неудачные попытки также расходуют номера.

## Развёртывание

Docker-образ включает Python, ReportLab и шаблон. После обновления пересоберите образ: `docker compose up -d --build`. Таблицы подписей и номеров создаются при старте без изменения существующих данных.
Миграция версии 2 сохраняет прежнюю единственную подпись каждого сотрудника и добавляет ей идентификатор. Лимит трёх подписей проверяется на сервере под блокировкой пользователя, включая одновременные запросы.

Локально установите ReportLab в Python-окружение и задайте `LETTER_PYTHON` путём к его исполняемому файлу. По умолчанию используется `python3`. Запускайте сервер из корня проекта.

Нужен `OPENAI_API_KEY`. `LETTER_MODEL` по умолчанию `gpt-4.1-mini`; модель должна поддерживать изображения, Structured Outputs и web search. Реальные запросы распознавания и поиска платные. Автотесты подменяют ИИ и не обращаются к внешним сервисам.
