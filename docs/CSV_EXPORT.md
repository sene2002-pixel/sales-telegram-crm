# Скачивание отчёта команды

Доступно администратору и руководителю. Менеджер не может выгружать отчёт команды, в том числе прямым запросом к API.

1. Откройте «Команда» и выберите даты «С» и «По».
2. Нажмите «Экспорт CSV». В обычном браузере файл скачивается браузером. В Telegram версии с поддержкой WebApp API 8.0+ появится системный запрос скачивания.
3. Если скачивание не поддерживается, отменилось или документ не появился, нажмите «Получить CSV в боте». Бот отправит документ лично вам. Откройте чат бота и сохраните файл средствами Telegram. Перед этим нужно начать личный диалог с ботом и не блокировать его.

Подтверждение запроса Telegram не означает, что файл уже сохранён. При ошибке отправки проверьте соединение сервера с Telegram и доступность бота, затем повторите. В демонстрационном входе отправка в бот недоступна.

## Что внутри

Одна строка на сотрудника: сотрудник, компании, открытые задачи, просроченные задачи, выполненные задачи, контакты, компании без контакта 14 дней. Это сводка, не выгрузка всех карточек и транскрипций. Контакты и выполненные задачи считаются за выбранный период включительно; остальные показатели — на момент формирования. Файл называется `team-report-ДАТА_С-ДАТА_ПО.csv`, кодировка UTF-8 с BOM, разделитель `;`. Его можно открыть в Excel/Numbers или импортировать как CSV с указанным разделителем.

## Настройка и безопасность

Новых API-ключей не требуется. Нужны существующий `BOT_TOKEN` и доступный публичный HTTPS-адрес сервиса в `PUBLIC_URL` (корень сайта, без `/app`). При локальном тестировании сервер и ngrok должны оставаться запущенными. Изменение адреса требует обновления конфигурации и настройки Telegram.

Для нативного скачивания сервер создаёт случайную ссылку на конкретный снимок CSV сроком на 5 минут. Сессионный токен в неё не включается; в БД хранится только хеш ключа ссылки. Не пересылайте ссылку: обладатель может скачать этот файл до её истечения. Доступ отзывается при блокировке владельца или снятии роли руководителя/администратора. Повторное скачивание до истечения разрешено для совместимости с Telegram. Одновременно допускается пять действующих ссылок на сотрудника. Истёкшие снимки удаляются при следующем создании ссылки; автоматически недоступны сразу после истечения.

Отправка ботом разрешена только на Telegram ID текущего авторизованного пользователя: выбрать другого получателя через API нельзя. Полученный в чате файл остаётся в истории Telegram, пока его не удалят средствами Telegram. Отзыв роли не удаляет уже скачанные/отправленные копии.

После слияния ветки пересоберите сервис: `docker compose up -d --build app`. Таблица временных выгрузок создаётся автоматически без удаления данных CRM. `.env` не нужно публиковать в GitHub.

Реализация основана на [Telegram WebApp.downloadFile](https://core.telegram.org/bots/webapps#downloadfileparams) и [Bot API sendDocument](https://core.telegram.org/bots/api#senddocument).

## Автоматические проверки

- `src/tests/roles.test.ts`: права каждой роли, обязательная авторизация создания ссылки, запрет чужого получателя, даты, заголовки скачивания, неизменность снимка, UTF-8 BOM, истечение и неизвестные ссылки, блокировка/понижение роли, лимит и очистка ссылок, адресат доставки и ошибки адаптера.
- `src/tests/export-adapter.test.ts`: multipart-документ, имя файла и содержимое, HTTP-ошибка и отказ Telegram.
- `e2e/csv.spec.ts`: скачивание браузером, вызов Telegram с HTTPS-ссылкой, отмена, старая версия клиента, ошибки API, подтверждение отправки ботом на мобильном и десктопном размерах. Telegram в этих тестах заменён заглушкой; сохранение на реальном телефоне проверяется после развёртывания.
