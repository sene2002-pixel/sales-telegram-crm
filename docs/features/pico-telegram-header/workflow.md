# Системная панель Telegram

Запрос: верхняя панель как на втором снимке пользователя, с названием бота по центру. Небольшая UI-коррекция после fullscreen. Дизайн: стандартный expanded Mini App сохраняет системные Close/title/menu Telegram; приложение не подделывает эту панель. Native title контролируется Telegram и настройками бота. Изменения имени/настроек production-бота не выполнялись. Browser mobile fallback показывает Pico Bot по центру без дополнительного значка. В Telegram authenticated initData дублирующее мобильное название скрыто; внутреннее меню приложения сохранено.

Реализация: expand при старте, без requestFullscreen; уже fullscreen-сессию выводим через exitFullscreen с поддержкой8.0 и безопасным fallback. Pinch, portrait, safe areas, auth неизменны. Откат — вернуть три frontend-файла; данных/миграций нет. Независимый Reviewer: PASS до QA. QA2: 18 viewport/auth PASS; layout 6 PASS после обновления четырёх прежних ожиданий видимого мобильного значка на центрированный текст (aggregate, не один чистый24 прогон). QA1: новый набор header 6/6 PASS: native auth, exitFullscreen, скрытое дублирование, доступное меню/фокус, центрированный browser title 360/390, sidebar1440. Product Owner: accepted в тестируемой области. Серверный код не менялся, backend повторно не запускался. Физический Telegram не проверен; системную панель браузерные тесты не рисуют.
