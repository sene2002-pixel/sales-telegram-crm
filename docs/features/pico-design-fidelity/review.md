# Исправить неполное соответствие интерфейса макетам Pico

После первого обновления форм оставались длинные поля, отсутствовали категории и направления оборудования, поставки и услуги проекта, компактное управление пользователями и часть действий участников. Это изменение приводит пять экранов и вложенные формы к структуре предоставленного PDF, сохраняет ввод при выборе клиента и исправляет размещение действий на коротком мобильном экране.

Добавлены совместимые ключи категорий и оборудования, серверное добавление пользователя по Telegram ID, подсказки задач из подтверждённых данных и сравнение аналитики по истории изменений. Старые направления без указанного напряжения сохраняются отдельно; недостаточная история показывается как недоступное сравнение.

Проверки: два независимых тестировщика, полный check (331 passed / 2 skipped, 7 ops, build), 74/74 E2E desktop/mobile и визуальное сравнение 50 снимков. Финальные результаты повторного UI-прогона приведены в workflow.md.

Источник требований — PDF пользователя. Задача Asana недоступна: MCP возвращает HTTP 401. Рабочая ветка codex/pico-design-fidelity; публикация и production-операции не выполнены. Учитывать совместимость новых JSON-ключей при откате; требуется резервная копия до выпуска.
