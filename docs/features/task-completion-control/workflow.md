# Явное завершение задачи

## Требования и решение

Источник: подтверждённый пункт локального аудита интерфейса от 2026-11-01. Отдельная карточка Asana для этого пункта не создавалась.

Иконка телефона/встречи/письма в TaskList выглядела как обозначение типа или команда звонка, но сразу изменяла `done`. Два аналитика подтвердили обработчик; частота случайных действий пользователей не измерялась.

Два дизайнера выбрали декоративную плитку типа вместо дополнительного чекбокса и строки метаданных. Сохраняем цвет, размер 40 px и иконку; убираем обработчик, фокус и семантику кнопки. Завершение и возврат доступны через существующие явно подписанные действия. Текст задачи раскрывает действия на главной «Сегодня» либо открывает карточку в остальных списках.

Критерии: нажатие плитки не отправляет PATCH и не меняет статус; текст по-прежнему открывает действия; явное завершение/возврат сохраняет дату, время, контакт; ошибка API не изображает успех. Проверяем все четыре типа, 320/390/1440 px и клавиатуру.

Небольшое исправление общего UI-компонента. API, ACL, хранение и миграции не меняются; серверная авторизация и version остаются прежними. Откат — revert PR.

## Этапы

- Анализ: passed, два аналитика, общий TaskList и существующие тесты.
- UX/дизайн до реализации: passed, два дизайнера, минимальный вариант без изменения плотности.
- Разработка: passed. В `TaskList` кнопка типа заменена на декоративный `span aria-hidden`; подписи, явные действия, размеры и цвета сохранены. Существующий UI-04 проходит через карточку, проверяя тот же цикл завершения/возврата.
- Два ревью кода: passed, `keyboard_code_review` и `swipe_code_review_2` проверили фактический diff и новые тесты перед QA; блокеров нет.
- Проверка готовой верстки: passed, два дизайнера лично открыли по пять снимков итерации 1 через `view_image`. Проверены списки 320/390/1440, раскрытые действия Today и завершённая задача. Замечаний, требующих изменения UI, нет.
- QA: passed. `npm run check`: 514 passed, 4 штатных skipped, 7 ops-тестов, сборка успешна. Playwright: 32 desktop + 32 mobile passed (`task-completion-control`, `features`, `static-home`, `design-fidelity`, `pico-finality`). Локальный сервер проходит `/api/health` при запуске Playwright.
- Приёмка: passed. Новая регрессия проверяет четыре типа без PATCH по плитке, отсутствие Tab stop, оба варианта Home, открытие по Enter/Space, ошибку 429 без ложного успеха, явное завершение и возврат с сохранением даты/времени/поля контакта и version. UI-04 проверяет цикл с настоящим локальным API, фильтры и календарь. Фото не доказывают поведение: его подтверждают тесты. Mobile — Chromium touch, физические Telegram/iOS/Android не проверялись.
- CI и выпуск: pending, только после проверок PR.

Воспроизводимые кадры: `/tmp/task-completion-{home,list,done}-{320,390,1440}-{desktop,mobile}.png`; снимаются новой спецификацией. API/ACL/данные и production-интеграции не изменялись. Предупреждение Vite о размере bundle остаётся прежним.
