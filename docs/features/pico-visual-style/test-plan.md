# Проверки

Автоматические сценарии: `e2e/pico-style.spec.ts`, два размера 375/1440 в проектах desktop/mobile.

- Название страницы, бренд, путь и загрузка аватара размером 1254 px.
- Цвет основной кнопки и текста.
- Отсутствие горизонтального переполнения страницы и формы письма.
- Менеджер не видит команду.
- Создание компании и контакта, открытие формы письма, компактные кнопки, отмена без оставшейся рамки.
- Отсутствие клиентских исключений.

Регрессия: `npm run check` — серверные тесты, эксплуатационные Python-тесты и сборка.

Не автоматизируется: установка фото живого бота через BotFather. Это отдельная проверка владельца после настройки.
