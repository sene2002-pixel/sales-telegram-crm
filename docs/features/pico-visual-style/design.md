# Дизайн и безопасность

Используется существующая реализация `src/web/main.tsx`, `src/web/styles.css`, `public/brand/pico-avatar.png` и `docs/assets/pico-style-reference.png`. Детали палитры — в `docs/PICO_VISUAL_STYLE.md`. Изображения локальные; новые внешние запросы и зависимости не добавляются. Роли, API и схема БД не меняются.

E2E проверяет вход, адаптивный бренд, цвета, отсутствие переполнения, компанию, контакт, открытие/отмену письма и отсутствие ошибок JavaScript. Playwright запускает отдельный сервер на 127.0.0.1:3107 с тестовой БД `data/e2e`, выключенными worker и внешними ключами.

Обнаружен риск: dotenv мог подставить DATABASE_URL и bootstrap администратора из рабочего .env. Эти значения теперь явно пустые в окружении тестового сервера; PUBLIC_URL локальный, диагностический срок очищен. Секреты не выводятся. Тесты не должны обращаться к рабочей PostgreSQL.

Откат: revert изменений конфигурации и документации в этой ветке. Миграции и восстановление рабочей БД не требуются. Тестовая БД содержит только синтетические данные.

Исправление QA: на 375 px длинный текст основной кнопки переносился, и кнопки письма имели разную высоту. Контейнер действий на узких экранах переведён на grid с одинаковыми строками. Текст не обрезается, проверка одинаковой высоты сохранена.

Фото живого бота: после явного разрешения пользователя проверен username `crm_svs_bot`, исходный PNG конвертирован в временный JPG (формат API), выполнен `setMyProfilePhoto`, затем `getUserProfilePhotos` подтвердил наличие фото. Токен прочитан локально, не выведен. Изменены только фото профиля, не команды, webhook или права. Для отката фото владелец выбирает прежнее изображение через BotFather; исходная предыдущая картинка в репозитории отсутствует.
