# Требования: визуальный стиль Pico

Источник: https://app.asana.com/1/1218599458205876/project/1218585786925552/task/1218585786925556 — прочитан 5 октября 2026.

Название: «Визуальный стиль, сделать аватарку и загрузить мокап для визуального стиля миниапки». Описание пустое; комментарий автора требует аватарку и стиль CRM по двум приложенным PNG. Реализация и исходные изображения уже находятся в текущей ветке. Повторно создавать аватар или добавлять бизнес-функции из иллюстрации не нужно.

Критерии приёмки:

1. Mini App показывает Pico и исходный аватар; заголовок и favicon соответствуют бренду.
2. Светлая палитра, белые карточки и индиго-акцент сохранены.
3. На 375 и 1440 px нет горизонтального переполнения; создание компании, контакта и форма письма работают.
4. Права менеджера не изменены; раздел команды ему недоступен.
5. Фото Telegram-бота соответствует готовому аватару. Пользователь отдельно разрешил изменение живого бота 5 октября 2026; фото установлено через Telegram Bot API.

Текущая итерация закрывает проверку существующего оформления, безопасный E2E-прогон и фото бота. Деплой, слияние и изменение Asana не выполняются.
