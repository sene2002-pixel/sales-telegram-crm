# Шторка контакта по тапу

Источник: Asana 1220118760111403. Ведущий прочитал описание, комментарии и вложения (дополнений нет), просмотрел фактический борд 17 «Клиенты — тап по контакту» в Pico Bot — финал. Текущая реализация уже имеет версионный редактор контакта по карандашу, но не по тапу, без выбранной строки и автоматического раскрытия за шторкой.

## Требования и решение

Тап/Enter/Space и карандаш открывают один редактор «Контакт», загружая актуальную версию записи. Только выбранный контакт получает рамку 1.5px #1F7AEA. Шторка использует существующий Modal: ручка 36×4, заголовок и крестик; 4 поля ФИО, Должность, Телефон, E-mail; подписи 14px/800/#2B3258, поля от 40px с фоном #F3F6FB и скруглением12, Save48px во всю ширину. Все значения переносятся и растут через общий GrowingTextarea; tel/email inputMode сохранены, email проверяется contactSchema. Низ скрыт при открытой форме. Выбранный контакт прокручивается выше верхней границы шторки; временное место под страницей позволяет прокрутить и последний контакт. Для слишком маленькой высоты/контакта выше доступной области показывается начало карточки — геометрически весь элемент может не помещаться.

Save обновляет запись существующим PATCH с открытой версией, затем список, закрывает и снимает рамку. Закрытие крестиком/фоном/Escape отменяет черновик без записи; на время отправки закрытие и поля блокированы, повторная отправка защищена ref-флагом. 409 и ошибки сохраняют черновик. Существующие права сервера, API и схема БД не меняются. Новых зависимостей нет. Откат: revert UI-коммита, миграций нет.
