# Названия компаний без юридической формы

Запрос из снимка пользователя: убрать из отображения «Акционерное общество», «ООО» и подобные добавки, затем отправить изменения в main вместе с fullscreen/portrait/zoom.

Дизайн: shared presentation helper removes anchored Russian legal forms (ООО/АО/ПАО/ОАО/ЗАО/НАО/ИП и полные формы), префикс или суффикс. Внешние кавычки снимаются после удаления юридической формы.
