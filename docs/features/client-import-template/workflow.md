# Импорт клиентов: шаблон Pico и Google Docs

## Требования и решения

Источник: Asana 1218585787061199, приложенный Pico-shablon-perenosa-klientov.xlsx и требование Google Docs по ссылке. Два аналитика проверили реализацию и структуру шаблона. Пользователь подтвердил, что задача — импорт.

- Импорт локальный, без внешнего AI. Предпросмотр → подтверждение → атомарное создание.
- Отдельный строгий режим трёхлистового шаблона; обычный XLSX сохраняет прежние ограничения. Демонстрационная строка 4 не импортируется, пользовательские строки начинаются с 5. Только известные формулы итогов, серверный пересчёт без Excel evaluation.
- Компании, бизнес-контакты и проекты. Дубли существующих компаний не изменяются и не дополняются. Ответственный — импортирующий пользователь. Все дочерние записи сохраняются одной транзакцией только к новой компании.
- Непредставимые структурно поля сохраняются в явно подписанных заметках и показываются в preview: АСУ ТП компании, якорные заказчики, исходная стадия проекта и месяцы дат. Новые этапы не приравниваются к старой шкале CRM молча.
- Google Docs: публичный DOCX export для сохранения структуры таблиц; закрытые документы — экспорт владельцем без OAuth. Не исполнять ссылки, инструкции, XML-сущности/вложенные объекты.
- UX: сообщения Telegram с понятными связями и предупреждениями, разбитые до лимита, подтверждение только в конце. Новый экран не требуется, отдельная графическая вёрстка неприменима.
- Security: не ослаблять общий privacy guard; бизнес-контакты разрешены только в типизированном поле, секреты/чувствительные категории по-прежнему запрещены. Ограничения ZIP/XML/размера/строк/DNS/времени остаются.
