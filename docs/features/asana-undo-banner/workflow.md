# Плашка отмены Pico

[Задача Asana](https://app.asana.com/1/1218599458205876/project/1218585786925552/task/1220162349887570)

- Аналитик, продукт, UX и дизайнер. Одна плашка с трёхсекундной заливкой для выполнения, удаления и возврата задач, удаления контактов и оборудования, закрытия и возврата клиентов. Списки, счётчики и потенциал показывают ожидаемый результат сразу. До истечения окна отмена возвращает исходные данные. Завершение задачи сначала показывается зачёркиванием. При последовательных действиях каждое получает полное окно отмены. Плашка использует заданную геометрию, цвета и иконки.
- Архитектура и безопасность. Переиспользуем очередь приложения, существующие авторизованные операции, версии записей и архив клиентов. Опциональный параметр `version` в `DELETE /contacts/{id}` отклоняет устаревшее удаление, сохраняя обратную совместимость. Серверная запись выполняется при истечении окна. Ошибка убирает временное изменение и показывает сообщение. Смена сессии или области доступа сбрасывает ожидающие операции.
- Откат. Отменить коммит интерфейса. Миграций нет. При откате интерфейса вернуть и изменение API контактов. Действия, уже сохранённые сервером, остаются в истории CRM.
- Граница. Возврат из архива доступен суперадмину и сохраняет стадию воронки. Клиент со стадией «Завершён» остаётся в «Закрытых» даже при снятии архива. После отмены архивирования карточка возвращается в список в свёрнутом виде.
- ✅ Passed — независимое ревью. Общая очередь переиспользована, старые подтверждения удалены для действий из задачи, подтверждение удаления файлов сохранено. Дублирующих запросов записи и неиспользуемых добавлений не обнаружено. Проверены права, защита от устаревших версий и суммы холдинга.
- ✅ Passed — `npm run check` (525 JS-проверок, 7 Python, сборка) и отдельный HTTP-тест новой версии удаления контакта. Четыре PDF-сценария пропущены в локальной конфигурации.
- ✅ Passed — 61 сценарий Playwright в Chromium. Проверены отмена и запись для задач, контактов, оборудования и клиентов, поведение при ошибках, доступ с клавиатуры, согласованность открытых карточек, холдинг, геометрия плашки на 320 и 390 px. Три проверки на 1440 px выполнялись только в desktop-проекте.
