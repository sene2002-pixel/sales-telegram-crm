# Свайп задач

Источник: [Asana 1220162350133983](https://app.asana.com/1/1218599458205876/project/1218585786925552/task/1220162350133983). Описание прочитано полностью; комментариев и вложений нет. Макет: Pico Bot — финал, борды «Задачи — свайп влево: правка и удаление» и «Задачи — удалена свайпом: плашка „Задача удалена“»; проверку источника выполняет ведущий агент.

## Требования и решение

- Вся активная ячейка задачи, включая иконку и текст, смещается влево на 112 px. Две зоны по 56 px, карандаш и корзина #6B7390, без подложек на фоне страницы.
- Правка повторяет тап по строке: шторка задачи, а на Главной сохранены прежние встроенные действия.
- Удаление без подтверждения вызывает существующую очередь TaskActions. Строка сразу скрыта, плашка даёт 3 секунды на отмену; до истечения окна нет запроса, после — существующий версионный PATCH с data.deleted=true, запись доступна в «Закрытых».
- Обратный жест, тап вне действий, Escape/ArrowRight закрывают раскрытие; клавиатурный ArrowLeft раскрывает. У завершённых/удалённых строк жест недоступен, сохранён существующий возврат через шторку.
- Переиспользован SwipeAction. Добавлен opt-in confirmDelete=false; остальные потребители по умолчанию сохраняют подтверждение. Обработчик удаления общий для обоих режимов, без дублирования мутации или обработки ошибок.
- TaskList получает прозрачный контейнер и отдельные белые скруглённые строки: область действий не создаёт белую плашку.

## Границы и безопасность

Нет изменений API, прав, БД, внешних интеграций и новых зависимостей. Используется существующая серверная авторизация и проверка версии. Отложенное удаление, ошибки PATCH, отмена при смене сессии и восстановление остаются в TaskActions. Откат — revert изменения UI; данные и миграции не затронуты. Реальный телефон для приёмки этой задачи не нужен: жест проверяется CDP touch в Chromium; это не утверждение о физической проверке iPhone.
