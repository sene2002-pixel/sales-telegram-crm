# Подсветка при касании

На сенсорном экране краткое нажатие не должно добавлять серую заливку к кнопкам, ссылкам и другим интерактивным элементам. Проверить нижнее меню, действия на главной и файл в карточке клиента. Выбранная вкладка, видимый фокус с клавиатуры и наведение мышью должны сохраняться.

Нативная подсветка WebKit отключена на уровне приложения. Стили наведения, которые перекрашивают элементы, действуют только в режиме точного указателя с поддержкой наведения. Правка касается только CSS. Для отката достаточно вернуть изменения стилей; миграции и обновление данных не требуются.

- ✅ Независимое ревью: лишний локальный сброс для цифровой клавиатуры удалён; выбранная вкладка и стили фокуса сохранены.
- ✅ WebKit, эмуляция iPhone 13: касания по нижнему меню, «Поделиться», «Позвонить клиенту» и файлу не меняют фон; переходы, открытие диалогов и загрузка файла работают.
- ✅ Chromium на компьютере: наведение мышью, видимый фокус и активация с клавиатуры работают.
- ✅ `npm run check`: 580 тестов Node.js прошли, 7 пропущены, 20 тестов Python и сборка прошли.
- 🟡 На физическом iPhone в Telegram не проверено.
