# Исправления вёрстки по снимкам пользователя

Scope: bounded UI bug, без изменений API/данных. Ветка `codex/pico-layout-regressions`, исходный коммит `9a7ca03`.

Требования: значки оборудования в аналитике остаются компактными квадратами, название получает свободное место; суммы не накладываются на текст. Корона администратора слева приветствия, пояснение непосредственно под текстом приветствия. Логотип и нижняя навигация корректно отображаются на узком и широком экране; два независимых тестировщика.

Причина: `.pico-potential summary > span { flex: 1 }` растягивал как текст, так и контейнер значка. Общий `.section-head h1` добавлял отступ и делал приветствие с короной несогласованным. Исправления ограничены разметкой HomeScreen/AnalyticsScreen и локальными стилями. Логотип уже PNG, а навигация SVG: не заменять их системными emoji. В раскрытых строках аналитики длинное имя клиента переносится, сумма сохраняется в одной строке.

Developer: выполнено; QA1: ACCEPTED, 6/6 Chromium desktop/mobile на 360/390/1440 px и 3/3 WebKit с локальным обходом HTTPS upgrade; QA2: независимый diff-review passed, check passed (331 / 2 skipped, 7 ops и build); полный E2E 80/80 (40 desktop, 40 mobile), в том числе 6 новых проверок на 360/390/1440 px. Тестовый сервер остановлен. Предыдущая визуальная приёмка не выявила растянутые значки: новые проверки должны измерять их размеры и положение текста, а также проверить реальные снимки.

Риски/откат: только CSS/DOM; возврат этих локальных изменений не меняет данные. Production и интеграции не используются. Публикация не выполнена.

Особенности локального QA: первый параллельный check завис в roles.test; изолированный прогон этой группы прошёл 90 тестов / 1 skipped, повторный полный check прошёл без ошибок. WebKit на локальном HTTP переводил CSS/JS на HTTPS из-за upgrade-insecure-requests; bypassCSP не устранил TLS-переход. Только в тестовом HTML-ответе удалена директива upgrade-insecure-requests; остальные директивы сохранены, настройки приложения не меняются. Проверка WebKit подтверждает геометрию, не production security.

Независимая визуальная приёмка: оставшихся блокеров нет. Проверены фиксированные badge 27×27 / SVG 16×16, суммы раскрытых строк без переносов и наложений, корона слева / подпись под приветствием с зазором 8 px, загрузка PNG и навигация SVG 21×21. Чистые снимки 390 px: `/tmp/pico-layout-final-390/home-390.png`, `/tmp/pico-layout-final-390/analytics-390.png`. Серверы QA остановлены. Публикация не выполнена.
