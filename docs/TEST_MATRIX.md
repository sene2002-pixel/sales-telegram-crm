# Матрица функциональных проверок

`BOT-04` в `roles.test.ts`: `/myid` для активного, неизвестного и заблокированного пользователя; ответ только со своим ID в личный чат; запрет групп и несовпадающих chat/from; отсутствие регистрации, отчётов и повышения прав; аргумент с чужим ID не влияет на ответ.

Эта матрица связывает [гайд ролей](ROLE_GUIDE.md) и [спецификацию](FEATURES.md) с исполняемыми тестами. Идентификатор в квадратных скобках можно найти в названии теста. Параметризованные проверки исполняются отдельно для manager, supervisor и admin. Для запретов проверяется HTTP-отказ, а не только отсутствие кнопки.

## Эксплуатация

`scripts/test_backup.py`: семь offline-проверок резервного копирования и восстановления. Они проверяют состав архива (SQL + файлы, без `.env`), права 0600, запрет перезаписи архива, остановку writers, обязательное подтверждение восстановления, SQL-транзакцию, восстановление байтов вложения и отказ от traversal/symlink. Команды Docker заменены тестовыми ответами — это **не** проверка реального pg_dump/psql или Docker volume.

## Как запустить

```sh
python3 -m venv .venv
npm ci
npm run check
npx playwright install chromium
npm run test:e2e
npm run format:check
```

`npm run check` включает серверные тесты, Python-тесты и сборку. CI дополнительно запускает серверные сценарии на PostgreSQL 17 в отдельной случайной схеме; локально по умолчанию используется отдельный временный PGlite. Рабочая БД не используется тестами.

Для отдельной проверки PostgreSQL задайте `TEST_DATABASE_URL` тестового экземпляра и выполните `npm test`. Пользователь БД должен иметь права CREATE SCHEMA; тесты создают и удаляют только свою случайную схему.

## Что остаётся ручной приёмкой

Нельзя заявлять «каждый пункт проверен в production» на основании тестов с адаптерами. Качество распознавания речи, фактическая доступность моделей аккаунту, Telegram iOS/Android, публичный HTTPS, BotFather, живой webhook, полный Docker backup/restore, восстановление после отказа диска, мониторинг и настройки защиты main проверяются отдельно по OPERATIONS.md. Автотесты не доказывают фактическую точность утверждений ИИ или юридическое соответствие хранения данных.
