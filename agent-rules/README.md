# Справочники ролей CRM

Правила проекта — в ../AGENTS.md. Глобальный development-orchestrator задаёт процесс, адаптивную глубину и контрольные точки. Файлы roles/, skills/, workflows/ и templates/ сохранены как дополнительные справочники; не требуют отдельных обязательных документов или повторного разрешения пользователя. Специализированный skill применяй только по задаче и с учётом текущих правил сессии.
