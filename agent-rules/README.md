# Agent workflow

Это проектный набор правил для AI-команды CRM. Общие правила находятся в `../AGENTS.md`, роли — в `roles/`, процессы — в `workflows/`, шаблоны — в `templates/`.

В Codex явно указывай нужную роль, например: «Используй `analyst` и подготовь требования для follow-up». Для большой функции запускай workflow `workflows/new-feature.md`.

Каталог назван `agent-rules`, потому что системный `.agents/` на текущем рабочем окружении доступен только для чтения; содержимое всё равно версионируется вместе с репозиторием и может быть перенесено в `.agents/` при необходимости.
